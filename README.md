# doopley

Doopley is now (was for a long time) a module script that can be found [here](https://create.roblox.com/store/asset/18833678282/doopley), that can be run in any game. If you want to look at the source, just import the asset into studio, no repo will be made for the module.
<br>
<br>
Due to Roblox's very restrictive and random rules regarding audios in toolbox assets and their [very unhelpful moderation messages](https://x.com/srth_h/status/1899861616792834404) when it comes to their system for detecting "malicious" assets, doopley dosen't really get updated anymore, and most updates are just small tweaks and mabye messing around with new experimental features, like the text to speech.
